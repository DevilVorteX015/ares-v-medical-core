# ARES-V // Edge-AI Medical Core

Simulador de monitoreo biomédico autónomo para misiones de tránsito a Marte basado en estándares NASA LSAH / HRP.

## Archivos principales
- `index.html`: Interfaz táctil y motor de diagnóstico Edge-AI con asistente ARES.
- `ares_mission_config.txt`: Archivo editable con parámetros de misión, astronautas, umbrales e instrucciones médicas.
- `netlify.toml`: Configuración de actualización instantánea sin caché.
